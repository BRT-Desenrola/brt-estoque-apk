# BRT Estoque — APK

Repositório público só pra hospedar o APK do app BRT Estoque via GitHub Releases.

## Como publicar nova versão

1. Vai em [Releases](../../releases) → "Draft a new release"
2. Cria uma tag nova (ex: `v1.0.0`)
3. Anexa o arquivo `.apk` em "Attach binaries"
4. Publica

O link direto do asset (formato `https://github.com/BRT-Desenrola/brt-estoque-apk/releases/download/<tag>/<arquivo>.apk`) é usado na landing page de download: [brt-estoque-lp](https://github.com/BRT-Desenrola/brt-estoque-lp).
